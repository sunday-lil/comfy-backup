# 🎬 分镜规划指南

## 一、提示词写法

### 1.1 文生图提示词公式（静态）

```
主体 + 环境 + 细节 + 风格 + 构图
```

**示例**：
```
一个小男孩坐在教室电脑前，眼睛专注地盯着屏幕
蓝色T恤，黑色短发，笑得很开心
阳光从窗户照进来，温暖明亮
小红书摄影风格，高清8K，色彩明亮
正面中景构图
```

### 1.2 图生视频提示词公式（动态）

```
[主体] + [动作] + [运动方向] + [镜头运动] + [时长感觉]
```

**核心要素**（按重要性排序）：

| 要素 | 说明 | 示例 |
|------|------|------|
| **1. 主体动作** | 什么在动，怎么动 | "小男孩转头看向窗外" |
| **2. 运动方向** | 从哪到哪 | "从左到右" / "逐渐后退" |
| **3. 镜头运动** | 推/拉/摇/移 | "镜头慢慢推进" / "镜头跟随" |
| **4. 环境变化** | 光线/天气变化 | "阳光渐渐变暗" |
| **5. 情绪节奏** | 快/慢/紧张/放松 | "动作轻柔缓慢" |

**❌ 错误示例**：
```
"walk away"           → 太简单，模型自由发挥
"小男孩走路"          → 缺少方向和镜头
```

**✅ 正确示例**：
```
小男孩从画面中心向左走去，回头看了一眼镜头
镜头轻微跟随，保持人物在画面左侧三分之一处
动作自然流畅，环境光线柔和
```

## 二、分镜规划流程

### Step 1: 确定视频主线（你要讲什么故事？）

```
例：教孩子学编程的短视频
主线：小男孩学编程，从不会到会，开心展示成果
```

### Step 2: 拆分成多个镜头

| 镜头 | 时长 | 内容 | 图片提示词 | 视频提示词 |
|------|------|------|-----------|-----------|
| 镜头1 | 5秒 | 小男孩坐在电脑前 | 近景，教室，小男孩认真看屏幕 | 小男孩头部微微前倾，眼睛专注地盯着屏幕，手指在键盘上轻轻敲击 |
| 镜头2 | 5秒 | 特写键盘/代码 | 俯拍，键盘特写，屏幕显示Python代码 | 镜头从键盘缓慢推到屏幕，代码逐行高亮显示 |
| 镜头3 | 5秒 | 小男孩兴奋转头 | 小男孩转头看向镜头，笑 | 小男孩突然转头看向镜头，眼睛发亮，笑容灿烂，镜头轻微前推 |
| 镜头4 | 5秒 | 小男孩指着屏幕 | 小男孩手指向屏幕 | 小男孩手从下方进入画面指向屏幕，身体微微前倾 |

### Step 3: 写出每组提示词

## 三、实用模板

### 3.1 常用动作词库

**人物动作**：
```
转头、回头、点头、摇头、举手、挥手、起身、坐下
走来、跑向、后退、转身、弯腰、站起、拍手、指向
眨眼、微笑、大笑、皱眉、张嘴、叹气
```

**镜头运动**：
```
镜头推进、镜头拉远、镜头左摇、镜头右移
镜头跟随、镜头固定、缓慢推近、快速拉远

```
阳光渐渐变暗、光线变亮、阴影移动

## 五、wan2.2 特定技巧

### 5.1 分辨率匹配
- wan2.2 输出是 **640×640**
- 文生图是 **1024×1024**
- **建议**：先生成 1024×1024 图像，然后用 **Crop** 节点裁成 640×640

### 5.2 帧数和时长
- 81帧 @ 16fps ≈ 5秒
- 每5秒一个镜头刚刚好
- 10秒内容 = 2个连续镜头

### 5.3 动作幅度
- wan2.2 适合**小幅度的自然运动**
- 避免：大幅度的跑跳、剧烈动作
- 适合：表情变化、手部动作、轻微身体移动

## 六、生成顺序

```
1. 先规划好所有镜头（填分镜表）
   ↓
2. 用文生图生成所有需要的起始图
   ↓
3. 确认图片满意后，用图生视频逐个生成
   ↓
4. TTS 配音（可以提前录好）
   ↓
5. FFmpeg 拼接所有视频片段
   ↓
6. 最终合并音视频
```
