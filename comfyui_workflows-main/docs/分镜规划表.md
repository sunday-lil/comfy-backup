│ 风格：摄影/动画/水彩/电影质感                               │

┌─────────────────────────────────────────────────────────┐
│ 【视频提示词】图生视频用（要发生的运动）                     │
├─────────────────────────────────────────────────────────┤
│ 主体动作：怎么动                                           │
│ 运动方向：从哪到哪                                         │
│ 镜头运动：推/拉/移/跟                                     │
│ 节奏情绪：快/慢/活泼/舒缓                                   │
