# 🎬 视频一致性保障方案

## 问题诊断

| 问题 | AI 视频为什么会出错 | 解决方案 |
|------|---------------------|---------|
| 角色变脸 | 每段独立生成 | **角色定妆照 + 参考图** |
| 场景跳变 | 提示词不统一 | **固定风格词包** |
| 动作不连贯 | 没设计物理衔接 | **分镜位置衔接图** |

---

## 一、角色定妆照制度

### 1.1 先各生成一张"官方定妆照"

**白狐定妆照**（镜头1、3共用）：

```
主体外观（必须完全一致）：
- 通体雪白毛发，无杂色
- 宝石蓝眼睛，杏仁形状
- 大尾巴，蓬松浓密，约占身长2/3
- 体型：成年狐狸大小，胖嘟嘟可爱
- 鼻子：黑色小三角
- 耳朵：三角形，毛茸茸，内侧粉红

固定风格词：
中国古风水墨风格，雪景，冬季仙境
```

**樵夫定妆照**（镜头2、3共用）：

```
主体外观（必须完全一致）：
- 国字脸，络腮胡子，憨厚朴实
- 粗布麻衣外套，内衬白色棉衣
- 黑色棉裤，草鞋
- 肩扛柴担（固定道具）
- 身高约170cm，壮实身材
- 皮肤古铜色，皱纹

固定风格词：
中国古风，水墨画意境，朴实农民形象
```

### 1.2 每个镜头都用定妆照作为风格锚点

```
镜头1：白狐躺雪地
  → 参考图 = 白狐定妆照
  → 描述词包含全部外观特征

镜头2：樵夫走来
  → 参考图 = 樵夫定妆照
  → 描述词包含全部外观特征

镜头3：送酱板鸭
  → 参考图 = 白狐定妆照 + 樵夫定妆照
  → 描述词包含全部外观特征
```

## 二、场景风格统一方案

### 2.1 强制风格词包（每个镜头都要包含）

```markdown
# 基础风格（必须每次都写）
中国古风水墨风格，雪景，冬季

# 色彩基调（保持统一）
- 雪白、银白、淡蓝（环境）
- 暖阳金黄（光线）
- 低饱和度水墨感

# 光线（保持统一）
冬季柔和阳光，侧逆光
人物呼出白色哈气

# 画质（保持统一）
水墨渲染质感，高清细腻，8K
```

### 2.2 负面提示词统一包

```
色调艳丽，过曝，静态
细节模糊，字幕，风格化作品
画面，静态，最差质量
低质量，JPEG残留，丑陋
残缺，多余手指，畸形手部
脸部畸形，毁容，肢体畸形
```

## 三、物理位置衔接设计

### 3.1 三镜头位置图

```
【镜头1】白狐躺在雪地
┌─────────────────────────────────┐
│                                 │
│      🦊（白狐）                  │
│       头朝右 →                   │
│                                 │
└─────────────────────────────────┘
          结束动作：白狐头转向右边，看向镜头外

【镜头2】樵夫从右侧走来
┌─────────────────────────────────┐
│                        ↓       │
│                        ↓       │
│      🦊 ←←←←←←←←👤（樵夫）      │
│     （视线迎接）      从右侧走来   │
└─────────────────────────────────┘
          衔接：樵夫从白狐视线方向出现

【镜头3】樵夫蹲在白狐面前
┌─────────────────────────────────┐
│                                 │
│        🦊                       │
│       ↘                         │
│         👤（蹲下）               │
│                                 │
└─────────────────────────────────┘
          衔接：樵夫走到白狐面前蹲下
```

### 3.2 动作衔接设计

| 镜头 | 结束动作 | 下一个镜头开始 | 衔接点 |
|------|---------|----------------|-------|
| 镜头1 | 白狐转头向右看 | 樵夫从右侧出现 | 视线迎接 |
| 镜头2 | 樵夫走到白狐前 | 樵夫蹲下 | 位置到达 |
| 镜头3 | 白狐伸爪触碰鸭 | 结尾温馨定格 | 自然动作 |

## 四、Wan2.2 具体操作

### 4.1 工作流调整建议

wan2.2 图生视频支持**参考图输入**，可以：

```
1. 镜头1：
   - 输入：白狐定妆照（躺着的姿势）
   - 提示词：白狐转耳、摇尾、呼出热气...

2. 镜头2：
   - 输入：樵夫定妆照（站立姿势）
   - 提示词：踩雪、柴担晃动、走向画面左侧...

3. 镜头3：
   - 输入：白狐定妆照 + 樵夫定妆照（双人）
   - 提示词：蹲下放鸭、白狐伸爪、抚摸...
```

### 4.2 统一种子值

```
每个镜头的 KSampler 都用同一个负向提示词（保持质量一致）
```

## 五、生成执行清单

```
□ 步骤1：生成白狐定妆照（保存，作为后续参考）
□ 步骤2：生成樵夫定妆照（保存，作为后续参考）
□ 步骤3：检查定妆照，确认角色外观满意
□ 步骤4：镜头1文生图 → 用白狐定妆照作参考
□ 步骤5：镜头1图生视频 → 用镜头1图片 + 白狐定妆照
□ 步骤6：镜头2文生图 → 用樵夫定妆照作参考
□ 步骤7：镜头2图生视频 → 用镜头2图片 + 樵夫定妆照
□ 步骤8：镜头3文生图 → 同时用两个定妆照
□ 步骤9：镜头3图生视频 → 同时用两个定妆照
□ 步骤10：检查3个视频的连贯性
□ 步骤11：拼接 + TTS + 最终合并
```

## 六、检查要点

```
□ 白狐：始终是白色、蓝眼、大尾巴？
□ 樵夫：始终是粗布麻衣、络腮胡、扛柴担？
□ 雪景：始终有雪、白狐呼出白气？
□ 风格：始终是中国古风水墨风？
□ 衔接：樵夫是不是从白狐看的方向走来？
```

---

## 七、如果出现不一致怎么办

| 问题 | 解决方法 |
|------|---------|
| 白狐颜色变了 | 在提示词里更强调"通体雪白" |
| 樵夫脸变了 | 在提示词里加"同一个人" |
| 场景色调不一致 | 统一用同一个风格词包 |
| 雪景消失了 | 加"雪景"到正向提示词 |
| 动作很奇怪 | 简化动作描述，wan2.2擅长小幅动作 |
