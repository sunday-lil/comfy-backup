## 注意事项

1. **风格统一**：3个镜头都是中国古风水墨风格，色彩要协调（雪地蓝白、暖阳金黄）
2. **wan2.2 分辨率**：图生视频固定 640×640，建议文生图先裁剪再输入
3. **镜头衔接**：镜头1结尾和镜头2开头可以用雪景空镜头过渡
4. **酱板鸭细节**：镜头3要突出酱板鸭的油亮质感，让樵夫的手部动作清晰可见
